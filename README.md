# ムシャーナドリームダービー（ゆめのかけら 記録ツール）

ポケモンスリープで **「ゆめのかけらゲットS」** が発動したときのスクショを入れるだけで、
ゆめのかけらの量を **週ごとの表（月〜日 × 発動回数）** に自動で記録するツールです。

スマホでもパソコンでも動きます。記録はブラウザに自動保存されるので、
ページを閉じても消えません。**画像はブラウザの中だけで読み取り、どこにも送られません。**

---

## 使い方

1. `サイトを開く.bat` をダブルクリック（またはスマホなら公開URL）でページを開く
2. 「準備OK」と緑の文字が出るまで少し待つ（初回だけ数秒〜十数秒かかる）
3. 点線の枠にスクショをドラッグ＆ドロップ（スマホは枠をタップして写真を選ぶ）。
   何枚まとめてでもOK。パソコンなら Ctrl+V で貼り付けても読めます
4. 読み取った数字が出るので、間違っていないか確認
   （違っていたら数字の欄を直す。読めなかったら手で打つ）
5. 「記録する日付」を確認して、**「まとめて表に追加」** を押す

表の数字のマスをタップすると、その1件を直したり消したりできます。
「1つ戻す」で直前の操作を取り消せます。

---

## 表について

- **第1週は 2026/9/21(月)〜9/27(日)**。以降、月曜はじまりで週が切り替わります
- 「◀ 前の週」「次の週 ▶」で過去の週も見られます
- 列は最低7つ。1日に7回より多く発動した週は、自動で列が増えます
- 右端に **合計・発動回数・平均**、一番下に **週計** が出ます
- **メモ**欄に「キャンチケあり」などをその週のメモとして残せます
- **「表を画像で保存」** を押すと、表を1枚の画像（PNG）にして保存できます（提出用）。
  パソコンは「ダウンロード」ボタン、スマホは画像を長押し→「写真に保存」でもOK
- 「表をコピー」を押すと、Google スプレッドシートや Excel にそのまま貼り付けられる形でコピーします

## ファイル

| ファイル | 役目 |
|---|---|
| `index.html` | ページ本体（見た目・動き・読み取り処理ぜんぶ入り） |
| `musharna.png` | タイトル横のムシャーナのイラスト（背景を透明にしたもの） |
| `icon-180.png` `icon-192.png` `icon-512.png` | スマホの「ホーム画面に追加」用アイコン |
| `manifest.json` | ホーム画面に追加したときの名前や色の設定 |
| `サイトを開く.bat` | ダブルクリックでパソコンのブラウザで開く |

読み取り（OCR）には **Tesseract.js** というライブラリを使っています。
ページを開いたときにネットから読み込むので、**初回はネット接続が必要**です。

---

## しくみ（読み取りのコツ）

スクショ全体をそのまま読ませると誤読が多いので、
「画像の下側だけ切り出す → 2倍に拡大 → 白黒にする → 数字と x だけを探す」
という下ごしらえをしてから読み取っています。
それでも見つからないときは、切り出す範囲を広げて2回やり直します。
